sumcli

Install the Summation CLI (summation-cli on PyPI).

macOS / Linux

curl -fsSL https://install.summation.com/sumcli | sh

Inspect first: curl -fsSL https://install.summation.com/sumcli | less · view script

Windows (PowerShell)

irm https://install.summation.com/sumcli.ps1 | iex

Inspect first: irm https://install.summation.com/sumcli.ps1 | more · view script

Windows (cmd.exe)

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://install.summation.com/sumcli.ps1 | iex"

Same installer as PowerShell; cmd.exe just launches it. Or run sumcli.cmd.

Already have uv?

uv tool install summation-cli
